# French glossary (settled 7 October 2026)

Status: settled with the user on 7 October 2026. The "French" column is
binding for every French catalogue string. The user accepted keeping a few
English feature names (Inbox, Focus) where they are short and already familiar. Chrome's own French UI terms are reused
where EveryTab touches them (Nouvel onglet, Panneau latéral, Groupe d'onglets,
Historique de navigation, Paramètres).

## Conventions

- Address the user as **vous**. Neutral, international, and what Chrome does.
- French sentence case: "Boîte de réception", never "Boîte de Réception".
- Buttons use the infinitive ("Enregistrer", "Restaurer"), not the imperative.
- Narrow no-break space before `?`, `!`, `:`, `;` (U+202F), and « guillemets »
  for quoted titles. Numbers and dates come from Intl with the fr locale.
- "Enregistrer" is save; "sauvegarde" is reserved for Vault backups and
  Restore points. "Supprimer" is delete; "Retirer" is remove from a set.
- Keep the English term only where it is the proper noun: EveryTab, Chrome.
