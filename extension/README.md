# EveryTab extension source

Load this directory unpacked from `chrome://extensions` with Developer mode
enabled. There is no build step. Reloading the extension picks up source edits.

Start with the [project README](../README.md), [architecture](../ARCHITECTURE.md),
and [test guide](../TESTING.md). Maintained developer tools are in `../tools/`;
historical prototypes and previous specifications are in `../archive/`.

Chrome shortcuts can be configured at `chrome://extensions/shortcuts`.
The runtime version lives in `manifest.json`. This source tree is not a
published release; packaging remains paused pending explicit approval.
